# 🏋️ Gym Management System v2.0

A comprehensive C++ application for gym membership and subscription management.

## 🌟 Features

- Complete CRUD operations
- Subscription management system
- Automatic date calculations
- Input validation
- File-based persistence

## 🚀 Quick Start
```bash
g++ -std=c++17 code/GymManagementSystem.cpp -o GymManagementSystem
./GymManagementSystem
```
